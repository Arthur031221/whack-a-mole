# 打地鼠大作戰 Whack-a-Mole

夜市遊樂場風格的打地鼠小遊戲。30 秒內打地鼠、避開炸彈、打出連擊，挑戰各難度最高分。

單一 `index.html`，沒有任何框架，直接用瀏覽器開啟即可遊玩。

## 玩法

| 目標 | 分數 | 說明 |
|---|---|---|
| 地鼠 | +10 | 最常出現 |
| 金色地鼠 | +30 | 停留時間很短 |
| 炸彈 | −20 | 連擊歸零，別碰 |

- 連續打中，每 5 次連擊倍率 +0.5（最高 ×2）。
- 點到炸彈或點空洞，連擊歸零。
- 三種難度：簡單、普通、困難。最高分各難度分開記錄，存在瀏覽器的 localStorage。
- 操作：滑鼠點擊、手機觸控，或鍵盤數字鍵 1–9（排列同數字鍵盤）。`P` 或 `Esc` 暫停。

## 技術

HTML / CSS / JavaScript，單檔。角色以內嵌 SVG 繪製，特效使用 Canvas，音效使用 Web Audio API 即時合成（無外部音檔）。
